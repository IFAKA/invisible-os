# Nomon origin and license

`ClickModel.kt` is ported from Nomon, a single-switch (one click) input method:

- Broderick and MacKay, "Fast and flexible selection with a single switch", PLoS ONE 2009. Code: https://github.com/tbroderick/Nomon (GPL v3).
- Bonaker et al., Nomon-Simulation (CHI 2022, arXiv 2204.01619): https://github.com/nbonaker/Nomon-Simulation. The files ported are listed in the header of `ClickModel.kt`. That repository's core files carry an MIT license text; the original Nomon keyboard is GPL v3.

Because the port derives from GPL v3 code, `ClickModel.kt` is a derived work under GPL v3 (https://www.gnu.org/licenses/gpl-3.0.html). Keep this file and the header comment with it. Check the license of the whole app before it is shared or published.
